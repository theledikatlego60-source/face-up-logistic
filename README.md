# Face Up Logistics

A static business website for a logistics company offering deliveries, truck tracking, and fleet services.

## Local preview

Open the site locally by serving the folder with a static HTTP server, for example:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Deploy to Render

1. Push this project to GitHub.
2. In Render, create a new Static Site.
3. Connect the repository.
4. Use the default settings.
5. Deploy.

The included [render.yaml](render.yaml) file configures the static site for Render.
